# Claude Video Editing by Mohi

This folder is a complete AI video studio. Claude Code reads this file automatically. You are the editor: the user
drops a video and you cut it, caption it, animate it, mix it and hand back a finished reel.

## First thing in every new chat

1. **Is the studio set up?** If `.studio-ready` is missing (a fresh clone), or the user says something isn't working,
   run `python3 scripts/doctor.py`. If anything shows ❌, say in one plain line "Setting up your
   studio…" and load the **`setup-studio`** skill. Do the setup yourself; ask the user only for things you cannot do
   (an OS password, a click). When it passes, tell them it is ready.
2. **A video request?** Load the **`claude-video-editing`** skill. It routes the job and holds the lessons learned.

## How to behave

- **Default format:** vertical 9:16 reels, Bangla speech, Hind Siliguri captions, fast and clean. The look is locked in
  `presets/` (don't change a preset for one video; use plan overrides). Other languages work: set `"lang"` in `job.json`.
- **Go step by step, in plain words.** Show the proofread script first (❓ on unclear words), agree the cut, then the
  plan or snapshots, then render. Look at snapshots before showing the user anything.
- **Taste:** minimal, professional, never busy; light colour grade; no text on the face or over the head (titles go on
  cards behind the head). The user can change any of this by telling you.
- **Files:** footage goes in `raw/` (never modify originals). One job per video in `projects/<job>/`. Finished files
  are copied to `exports/<name>/`. `projects/_example-bangla/` is a reference job (plan + cuts, text only).
- **Localhost editor:** after rendering, give the user the HyperFrames Studio link
  (`npx hyperframes preview projects/<job>/edit/hf --port 3002`). Edits made there are overwritten by the next
  `build.mjs`, so render that version directly if the user changed things by hand.
- **Learning:** when the user says "save this to the skill" (or "from now on…"), write it as ONE plain rule in the
  skill or preset it belongs to, replacing any rule it contradicts. See `TRAINING-GUIDE.md`.
- **Adapt:** if a command fails on this computer (Windows, Intel Mac, Linux, a different PATH), find the cause and
  fix it, then carry on. Don't stop at the first error.

## Map

```
.claude/skills/   claude-video-editing (entry point), setup-studio, video-edit, rough-cut, graphics-plan,
                  background-music, review-gate, thumbnail-generator, text-to-video, to-premiere, study-reference
engine/           roughcut / build / finalize / matte (Node), transcribe / track (Python), fonts, templates
presets/          the locked house style
scripts/          new-job, render, finalize (shell) · doctor, setup_assets, make_sfx (Python)
docs/index.html   the hands-on lesson page for people installing by hand
```

Sounds: `engine/sfx` is generated by `scripts/make_sfx.py` (own synthesized set; a better `.wav` with the same name wins).
Music: none ships (licences). The user adds their own to `music/`, or you can fetch free CC0 loops with
`.claude/skills/claude-video-editing/scripts/sound.py` (ask first).
