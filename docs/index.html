Homebrew (Windows-এ winget)

কেন: পরের সব টুল এক লাইনে বসানোর "টুল-দোকান"। তাই সবার আগে।

MAC · TERMINAL-এ চালান (password লাগে)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" && echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile && eval "$(/opt/homebrew/bin/brew shellenv)" && brew --version && echo "✅ Homebrew installed"

Windows-এ কিছু করতে হবে না। winget Windows 10/11-এ আগে থেকেই থাকে। এটাই একমাত্র ধাপ যেখানে password লাগে, তাই Terminal-এ নিজে চালান (Cmd+Space → Terminal)।

FFmpeg

কেন: ভিডিও-অডিও কাটা, জোড়া আর শেষে render করে। এটা ছাড়া এডিট শুরুই হয় না।

CLAUDE CODE-এ PASTE করুন
Install FFmpeg (Homebrew on Mac, winget on Windows). Make sure both ffmpeg and ffprobe run. If anything fails, retry or choose a better alternative until it works. When done, reply only: ✅ FFmpeg installed

Node.js

কেন: HyperFrames আর আমাদের engine-এর স্ক্রিপ্ট Node দিয়ে চলে।

CLAUDE CODE-এ PASTE করুন
Install Node.js version 22 or newer (Homebrew on Mac, winget on Windows). Make sure node and npx run. If anything fails, retry or choose a better alternative until it works. When done, reply only: ✅ Node.js installed

Python

কেন: বাংলা শোনা, মুখ ট্র্যাক করা, আপনাকে কেটে আলাদা করা, এই কাজগুলো Python-এ।

CLAUDE CODE-এ PASTE করুন
Install uv (Homebrew on Mac, winget on Windows), then use it to create a Python 3.12 virtual environment at engine/.venv in this folder. Make sure it runs. If anything fails, retry or choose a better alternative until it works. When done, reply only: ✅ Python installed

HyperFrames

কেন: animation আঁকে, ভিডিও বানায়, আর আপনার localhost editor এটাই।

CLAUDE CODE-এ PASTE করুন
Set up HyperFrames: run npx -y hyperframes@latest skills (choose Claude Code), then run npx hyperframes doctor and fix anything that fails and matters (ignore Docker, Kokoro and MusicGen). If anything fails, retry or choose a better alternative until it works. When done, reply only: ✅ HyperFrames installed

কথা শোনা: Whisper + Parakeet

কেন: ভিডিওর কথা শুনে লেখা আর প্রতিটা শব্দের সময় বের করে। Whisper বাংলার জন্য, Parakeet English-এর জন্য। দুটো একসাথে।

CLAUDE CODE-এ PASTE করুন
Set up speech-to-text for Bangla and English. Bangla: install mlx-whisper together with opencv-python-headless, numpy and edge-tts into engine/.venv and download the model mlx-community/whisper-large-v3-mlx (on Windows use a working Whisper alternative such as faster-whisper). English: run npx hyperframes models install parakeet. Test both with a tiny sample. If anything fails, retry or choose a better alternative until it works. When done, reply only: ✅ Speech-to-text installed (Bangla + English)

Engine আর Skills

কেন: টুলগুলো ঠিক কোন ক্রমে, কোন style-এ চলবে তা বলে দেয়। এটাই আসল এডিটর। এটা এই folder-এই আছে (GitHub repo), শুধু ছোট কিছু জিনিস নামাতে হয়।

CLAUDE CODE-এ PASTE করুন
In this folder, run python3 scripts/setup_assets.py. It downloads the GSAP animation library, the noise remover for my computer, and generates the 24 sound effects. Then confirm .claude/skills contains the 11 skills. If anything fails, retry or choose a better alternative until it works. When done, reply only: ✅ Engine and skills ready, then remind me to open a new chat.

Skill শুধু নতুন chat শুরুর সময় load হয়, তাই এরপর নতুন chat খুলুন।

সবকিছু একসাথে যাচাই

শেষে একটাই লেখা: সব টুল ঠিক আছে কিনা এক নজরে ✅ বা ❌ দিয়ে জানায়, আর ❌ থাকলে নিজেই ঠিক করে।

নতুন chat-এ PASTE করুন
Run python3 scripts/doctor.py and show me the list. Fix every ❌ yourself (retry or choose a better alternative), then run it again until everything is ✅.

auto-editor, yt-dlp লাগবে না। ওগুলো শুধু লম্বা YouTube ভিডিওর আলাদা kit-এ লাগে, reels-এ নয়।

৬ ভিডিও দিন, দেখুন, ঠিক করুন

নতুন chat-এ আপনার ভিডিওর path দিয়ে এটা পাঠান। বাংলা বা ইংরেজি, যেটায় সুবিধা।

CLAUDE CODE-এ PASTE করুন
এই ভিডিওটা এডিট করো: /path/to/your-clip.MOV
একটা মিনিমাল, প্রফেশনাল বাংলা reel বানাও। রং স্বাভাবিক রাখো, শুধু হালকা grade।
পরিষ্কার বাংলা ক্যাপশন দাও। আমি যখন "AI দিয়ে এডিট" বলব, একটা AI chat বা editing timeline দেখাও।
"sound effect" বললে একটা sound icon দেখাও আর আওয়াজ বাজাও। প্রতিটা "animation"-এ আলাদা animation দেখাও।
আমার মুখের ওপর কোনো লেখা বসাবে না। টাইটেল আর লিস্ট আমার মাথার পেছনের glossy card-এ যাবে।
আগে আমাকে লেখাটা দেখাও, তারপর plan, তারপর render করো, আর শেষে localhost editor-এর link দাও।
  1. লেখা মেলানো: Claude কী শুনেছে দেখায়, ❓ চিহ্নিত শব্দ আপনি ঠিক করে দেন।
  2. Plan: কোন কথায় কোন animation বসবে, আপনি দেখে নেন।
  3. Localhost editor: Claude একটা link দেয় (যেমন http://localhost:3003)। খুলে লেখায় ক্লিক করে বদলান, বা Claude-কে সময় ধরে বলুন: "৬ সেকেন্ডে card-টা ছোট করো"।

মনে রাখুন: Studio-তে নিজে বদলালে Claude-কে জানান, নাহলে পরের বার বানানোর সময় আপনার বদল মুছে যেতে পারে। আর কোনো ভুল ধরলে বলুন "Save this to the skill", পরের ভিডিওতে ভুলটা আর হবে না।
